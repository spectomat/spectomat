`scripts/stop-hook.sh` and the state-file format written by `scripts/prepare.sh` derive from the `ralph-loop` plugin by Anthropic, licensed under the Apache License, Version 2.0 (`LICENSE-ralph-loop`). Changes: the state is `.spectomat/state.json`, the prompt fed back each iteration is fixed text generated by `pointer_prompt` in `scripts/utils.sh` rather than read from disk, and the setup prepares the factory floor before arming the hook.

Material condensed from [superpowers](https://github.com/obra/superpowers) 6.3.0 by Jesse Vincent, MIT License (`LICENSE-superpowers`), is carried by three agent briefs. `agents/review-spec.md` contains a condensed `spec-document-reviewer-prompt` from `brainstorming`, extended from an approve-or-flag reviewer into one that fixes the spec in place and records each fix as a decision. `agents/plan.md` contains a condensed `writing-plans`. `agents/implement.md` contains condensed `test-driven-development` and `systematic-debugging`, and a merge of `subagent-driven-development`, `executing-plans`, `requesting-code-review` and `receiving-code-review`. All of it is shortened and rewritten for an unattended flow: no questions to a human, no branches or worktrees, plan and work paths under `.spectomat/`, and the text inlined into the brief that uses it rather than kept as separate reference files.
